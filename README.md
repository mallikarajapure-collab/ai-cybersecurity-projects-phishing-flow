# 🔐 Phishing Detection System – Cybersecurity Flowchart

## 🌸 Overview
This project is a beginner-friendly cybersecurity flowchart that explains how phishing attacks are detected and prevented using a structured security system.

It helps in understanding how suspicious emails are analyzed and blocked to protect users from cyber threats.

---

## 🚀 How It Works

Email Received  
⬇️  
Suspicious Link Detection  
⬇️  
System Security Scan  
⬇️  
Risk Analysis (Safe / Unsafe)  
⬇️  
User Warning / Block Action  
⬇️  
Incident Report Generated
